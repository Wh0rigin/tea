# 第一阶段：命令能力与评测产物修复

[English](COMMAND_EXECUTION.md)

## 本阶段范围

针对 DeepSWE 中暴露的合法命令被拒绝、策略拒绝被误报为用户拒绝、Go 缓存环境缺失以及 Git 补丁导出失败，落实可复用实现。任务推进、ContextOS 工作集和完成判定留在后续阶段，逐项比较。

## 已修改

### 共用参数解析与命令策略

`run_tests`、`run_shell` 的策略判断与执行使用同一份解析后的 executable/argv。支持单双引号分组、带空格路径和双引号前的反斜杠转义；不进行 shell 展开。平衡引号内的 `|` 作为字面参数传递，例如 `go test ./pkg/cmd -run 'TestA|TestB'` 只启动一个进程。引号外的管道，以及原本禁止的分号、&、重定向、反引号和多行继续拦截，其他这些字符即使位于引号内也不放行。审批和危险操作检查保持有效；Windows npm 的 CMD 桥仍拒绝引号内的 `|`。

危险操作按实际可执行文件及 Git 子命令判断，避免将 `git log --format=...` 中的普通参数误当成系统 `format` 命令。常见 Git 日志参数顺序、分支查询、状态和 diff 参数可以执行；不支持的选项仍需审批。

新增 Go `test/build/vet` 与 Python 3 验证入口。帮助、收集、Git 查询和普通 CLI 调用不计入源码验证。Windows 原生 Node/Python/Git/Go 支持带引号参数；npm 的 CMD 桥单独限制元字符。

### 准确的审批结果

- 原有 `true/false` 回调兼容；`false` 表示回调未批准，不再推断为用户拒绝。
- 显式策略拒绝标记为 `COMMAND_POLICY_DENIED`。
- 终端用户拒绝标记为 `USER_APPROVAL_DENIED`。
- 无效返回值、回调异常、审批中取消均不执行命令。
- 可信宿主可附带有限的命令示例与策略版本，能力变化时只通知一次；描述不授予权限，不从仓库 AGENTS 自动加载策略。

### 必要的执行环境

子进程仅接收执行路径、系统/临时目录、必要 home 路径、Python UTF-8 与临时 Go 缓存配置；不复制任意环境变量或模型 API 凭据。工具权限仍不是 OS 沙箱。

### 可复用的评测权限与产物导出

评测权限工厂接收可信、冻结的项目 CLI 模块和基点，支持 `git checkout -b NAME main` 等分支形式、受限提交以及声明的 `python -m MODULE`。普通 CLI 可用不等于整题已经验证。

可信导出入口检查基点、忽略规则和私有状态，使用普通 `git add -A -- .`；提交前保存精确工作区补丁，之后导出提交补丁并比较 SHA-256。提交失败也保留原产物，已有文件不覆盖，禁止把产物写入任务源码目录。提交包含 DCO Signed-off-by。

下一版私有 Pier 适配器已接入共享权限工厂与导出 CLI；编码后若出现已知费用的基础设施异常，停止后续题目。旧付费运行的脚本、协议和结果保持原样。新适配器没有创建付费运行协议或启动模型调用。

## 验证结果

- Windows 完整回归：**380 通过、0 失败、1 跳过**，共 381 项；跳过项为本机未安装 Go 的真实测试。
- Linux 原始任务镜像、Node 24、禁用网络：**381/381 通过，无跳过**；包含普通 `run_tests` 执行真实 Go 测试。
- 测试覆盖原生引号路径、参数一致性、合法 Git format 参数与破坏性操作区分、Go 帮助不计验证、环境凭据隔离、策略/用户拒绝、无效审批、取消，以及真实 Python CLI。
- 产物测试走通**建分支 → 源码修改 → 测试 → 提交 → 导出 → 独立工作区应用补丁再测试**；同时检查仓库根目录边界、私有状态排除、既有产物不覆盖和提交失败保留补丁。
- 实际 Pier 适配器端到端预检通过：5 条固定 SSE 响应驱动 4 次真实工具调用，声明的 CLI、测试、提交和官方收集命令得到一致补丁哈希，再由独立容器应用并验证。**provider 调用 0**，属于自编基础设施夹具，不是 DeepSWE 任务成绩。
- 原有离线 runtime-smoke：**12/12 独立验收通过**；controlled replay 正常完成。脚本选择与序列化字节不代表真实模型正确率或 provider Token 收益。

服务器全量回归首次打包缺少测试夹具，随后为回归副本建立 Git 快照；准备失败日志均保留，最终完整回归通过。Pier 自编夹具首次因生成的 Python 字节码未忽略而发现额外产物，补齐该夹具的忽略规则后重跑通过，原失败保留；未给正式导出器加入会丢弃任意任务变更的过滤规则。服务器验证文件位于用户指定实验目录内，没有更改系统服务或安装新软件。

## 结论与下一阶段

本阶段确认修复后的命令与导出路径可用，未重新执行付费 DeepSWE，没有新的整题通过率或 Token 降低百分比。原来的 **0/2 整题结果不变**。

真实对照必须先冻结统一的合规评测权限，再比较相同任务、模型、思考等级、初始源码和预算。原两题作为回归，加入预选未见题；记录完整验收、全部调用和用量，未知账单停止。通过此阶段审核后，再单独实验任务推进与证据工作集策略。
