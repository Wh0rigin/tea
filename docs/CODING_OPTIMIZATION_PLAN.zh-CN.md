# 编码 Token 优化阶段

此列表对应 2026-10-14 的八题编码计划，与早期 SMALL_TASK_IMPROVEMENT_PLAN 的阶段编号分开。

- S0：固定八道编码题、初始文件、模型和验收，至少三次重复，区分功能和流程验收。
- S1：减少已有文件的创建误用。已撤销：Token 减少 1.38%，完整验收下降。
- S2：减少串行读取，试验批量文件读取。已撤销：全尝试 Token 增加 11.47%，并发现取消交付缓存缺陷。
- S3：精简工具说明和固定提示。当前阶段；先精简七个标准工具的说明，保持系统提示和能力通知原样。
- S4：压缩已解决的测试失败输出，保留未解决失败、待验证状态和可恢复日志。
- S5：提高测试编写与修复效率，区分实现缺陷和错误的测试预期。
- S6：试验可选 PowerShell 能力，接入批准、超时、输出限制、文件变化及证据失效。

每阶段独立与直接父版本对照；固定初始状态、模型、思考等级和输出上限。报告所有尝试、失败、未知用量和双方通过子集。无收益或质量下降则撤销；每阶段结束停下等待审核。
