# 已有文件与补丁错误反馈：实验协议

## 改动

- FILE_EXISTS：已有文件不能用 write_file 覆盖；已有当前源码证据可直接用于 apply_patch，仅缺失或过期时重读。
- PATCH_NOT_FOUND：检查搜索文本与当前源码，不把找不到匹配直接断言为版本变化。
- PATCH_AMBIGUOUS：利用已有证据增加唯一上下文，必要时读相关范围。
- 保留兼容 SOURCE_MISMATCH 的既有反馈；未引入没有实际版本检测支撑的 SOURCE_CHANGED 错误。

不自动把 write_file 转成覆盖写入，不放宽精确匹配、路径和权限检查。正常工具定义与系统提示没有改动。该改动发生在错误反馈，不能防止首次工具选错，也不能消除测试断言错误。
