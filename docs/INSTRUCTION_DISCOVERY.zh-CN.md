# 按需发现项目规则

TEA 启动时定向查找工作区根目录的 AGENTS.md；读取源码时，从根目录到目标所在目录查找适用的 AGENTS.md，并提示尚未完整读取或内容已更新的规则路径。请求路径与符号链接解析后的真实路径均参与发现。

规则发现不依赖初始文件清单排名，不扫描无关子树，不把所有规则全文塞入系统提示。模型仍使用 read_file 阅读规则，形成现有 ContextOS 可管理的源码证据。规则内容服从系统权限和当前用户要求。

已完整读取且 SHA-256 一致的规则不再提示；支持分段读取累计覆盖。手动修改内容后，下次读取对应范围的源码时重新提示。读取记录因缓存容量限制淘汰后，也可能再次提示。

这是一项发现与引导机制，不是强制读完才能编辑的安全门禁；模型直接编辑而没有读取目标源码时，不会自动触发该目标的目录规则发现。现有编辑权限规则继续独立执行。

当前仅支持工作区内 AGENTS.md，不实现用户级规则、AGENTS.override.md、规则导入、按文件 glob 匹配或技能加载。目录最多 32 层。规则文件沿用既有安全路径、UTF-8 和读取大小限制；无法正常读取的规则不能自动视为已遵守。工作区外文件不自动加载。

参考 Claude Code 的目录规则按需加载理念，未复制其配置语法或声称同等功能：[官方项目记忆文档](https://code.claude.com/docs/en/memory)。
