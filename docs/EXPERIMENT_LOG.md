## E10 — GLM-5.3-flash 原生 TEA/Pi 对比（2026-10-11）

- 目的：同任务、初始 Git/文件指纹、模型、API、思考模式/等级和输出上限下记录两套原生 agent 的实际服务商 Token，不将离线字节当作计费。

- 排除试跑：`tea-pi-glm-live-20261011` 的 111 次请求因 Pi 继承变化的祖先目录指令而不具备公平性，整轮排除并保留费用。新增祖先指令检查，全部 9 组在仓库外重跑。
- 有效 64,000 字节组：`tea-pi-glm-isolated-20261011`，9 组/105 次请求。TEA 168,282、Pi 161,046 Token，TEA 多 **4.49%**；验收 **9/9 对 7/9**。Pi 大型缓存/重试触发共同输入上限；失败保留，不当作同完成率节省。7 个双方通过子集少 25.44%，明确单列。
- 资源敏感性补测：事先选定全部 3 类大型任务，用双方相同的 80,000 字节上限，`tea-pi-glm-large-80k-20261011`，43 次请求。双方 **3/3**，TEA 117,126、Pi 107,674，TEA 多 **8.78%**；不与原配置拼接比例。
- 负收益：小型 Unicode 28,814/17,606；80k 大型重试 89,835/9,787，TEA 11 次请求/12 工具、Pi 5/4。中型 3 组均通过且 TEA 少 70.93%，不能只挑这一组宣称稳定优势。
- 全部有效已提交请求 usage 完整，计入普通输入/缓存读写/输出；未知不是零，思考不重复计数。图表同时标注失败原因和输入上限，原始路径/对话/凭据不公开。
- 冒烟、排除试跑、两种有效配置的保守费用共 **$0.69280956 / $3**；有效输入/输出 $0.72/$2.52 每百万、缓存读全价/写两倍预留，早期冒烟/试跑按 $0.80/$2.80。费率估算不是服务商账单。
- 全套确定性测试 **128/128**，本地实际双客户端协议检查通过；新增 Ubuntu/Windows × Node 20/22/24 CI，通过 PR 审阅。
- 限制：三类自编 JavaScript bug × 12/120/1,200 文件，每配置每任务一轮；规模主要增加无关模块、非保密 OS 隔离留出集，外部缓存不可清空。无稳定优势结论，无直接父版本优化门禁结论。
- 完整报告：[英文](../benchmarks/reports/tea-vs-pi-glm-20261011/README.md) / [中文](../benchmarks/reports/tea-vs-pi-glm-20261011/README.zh-CN.md)。下一项调查为大仓库发现与多余工具循环，需隔离改动、重复运行及真实仓库验证。

## E4 — 大量日志的有界返回（真实命令，离线）

- 发现：原工具 stdout/stderr 总量超过约 28k 时杀进程，随后只返回开头；正确或失败测试均无法得到完整退出状态和尾部断言。
- 改动：有界内存保存各流头尾/完整 SHA-256；成功每流 2k、失败 6.5k 字符；输出量不杀进程，超时仍结束 Windows 进程树。
- 实际命令比较：固定约 165k 字符日志，原版两项均 SIGTERM；候选完整取得 exit=0/1，成功返回 1,899（−86.47%），失败返回 6,448（−54.06%），均保留尾部结果。
- 延迟：候选约 1.66 秒，原提前中止约 0.37 秒，不构成速度改进证据。报告 `benchmarks/results/command-output-wKAWEz/report.json`。
- 决定：保留正确性与体积改善候选，provider Token 尚未测，不准入。

## E5 — 执行与计量缺陷修复

- 实际 Runtime 集成检查发现任务文本被错误传作 hash 算法名，启动即失败；改为 SHA-256 update(task)。
- Git 诊断/help/collect-only/Node 零通过测试不能满足编辑后验证；新编辑或后续验证失败恢复待验证，run_shell 中真正测试也计入。
- SSE 连续解码 UTF-8、消费尾部无换行事件；总输入包含普通/缓存读/缓存写，不重复累计流式计数。
- 缺失/无效/中断 usage、账本写失败不发布完整实测总量；保留已报告下界和本地保守费用预留。缓存写默认 2× 基础费率并非 Packy 实际账单。
- 安全运行 ID、防旧账本混入、导出 Live API 的有限价格/预算/整数上限、同 adapter 并发请求保护已覆盖。
