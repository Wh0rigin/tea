- **all** — legacy: 92.24% cached input, illustrative USD 1.010245; full: 93.65% cached input, illustrative USD 0.931663; contextos: 46.73% cached input, illustrative USD 0.696053. Illustrative cost reduction: +31.10% vs legacy / +25.29% vs full.

以上仅将实际缓存用量代入公开价格的敏感性计算：普通输入 USD 0.80/M、缓存读取 USD 0.23/M、输出 USD 2.80/M。不是账户账单，缓存折扣资格与转发路径未独立确认。减少的总 Token 仍包含缓存 Token；Token 降幅不能直接当成实际费用降幅。会变化的前置历史目录可能破坏缓存前缀，这是后续实验假设，尚未证明是这个 GLM 转发服务的机制。逐项计算见 [JSON](cache-price-sensitivity.json)。

### 补充核查

[额外核查](requirement-audit.json) 比对了 270 次真实完整源码读取哈希；恢复后新版本检查点读取 8/9。历史数值恢复与禁止重读/重跑旧命令也逐项保留。它们是事后附加核查，不修改预定门槛。

**验收覆盖缺口：** 完整历史组 `stale-resume` 第 2 次恢复后未请求重读检查点，已从认证日志核实。原门槛检查服务行为和外部文件未被篡改，没有检查这个额外读取要求。按更严格的事后要求计数，旧版 21/21、完整历史 20/21、C 21/21；C 三次均重读成功。上方 63/63 仅指冻结门槛，不代表所有自然语言指令均被完整执行。缺失样本没有删去或改成通过。

另对 60 个实际请求做哈希一致的[离线目录位置实验](prefix-counterfactual.json)，移动目录后平均请求字节仅减少约 0.07%；可复用序列化前缀略有增长，但不能当成服务商缓存命中。没有付费 D 试验，也未将未经实测的改动加入运行代码。

样本是自编任务，部分历史由脚本预置；Python 旧失败日志为合成。没有未见真实项目或跨模型泛化证据；Java 未做实际编译，TypeScript 未单独类型检查。默认保持完整历史，C 需主动开启。结构化任务记忆和来源版本不保证模型语义判断正确。
