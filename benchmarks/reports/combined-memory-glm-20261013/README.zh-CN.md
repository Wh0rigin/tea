# ContextOS＋自动压缩：四组组合测试

[English](README.md)

![实际 Token 对比](combined-tokens.png)

## 结果

48 次运行、12 个四组对照块，每个案例重复四次。相同 GLM-5.3-flash、enabled/low 思考、初始代码、历史种子和任务提示。运行时源码及 package 未修改；自动压缩默认仍关闭。

- **short**：组合相对单独 ContextOS 增加 1.61%；实际摘要调用 0 次。没有执行摘要，Token 差异不归因为自动压缩。
- **protected**：组合相对单独 ContextOS 减少 40.55%；实际摘要调用 4 次。摘要实际生效，已计入其费用。
- **evictable**：组合相对单独 ContextOS 减少 13.58%；实际摘要调用 0 次。没有执行摘要，Token 差异不归因为自动压缩。

三案例合计：组合相对单独 ContextOS **减少 31.26%**。合计包含未触发摘要的对照，不能解释为每个任务都能获得相同节省。

- full_off：842,498 Token；完整验收 11/12；摘要请求 0 次、摘要 Token 0、有效检查点 0 次。
- full_auto：442,426 Token；完整验收 12/12；摘要请求 8 次、摘要 Token 47,609、有效检查点 8 次。
- contextos_off：443,394 Token；完整验收 12/12；摘要请求 0 次、摘要 Token 0、有效检查点 0 次。
- contextos_auto：304,771 Token；完整验收 12/12；摘要请求 4 次、摘要 Token 18,126、有效检查点 4 次。


相对单独摘要，组合合计少 31.11%；但受保护历史里组合反而多 13.61%（161,659 → 183,653）。叠加不能保证优于每个单独机制。

真实受保护组合组里，摘要后 27 次任务请求中有 12 次未声明历史搜索入口，四次运行的首个摘要后请求均缺少入口；后续 ContextOS 回收其他内容时可以再开放，普通修复仍通过。evictable 的 full_off 第一次重复在修复前停止：下一请求 81,838 字节，超过 80,000 保护上限；此前已计费的 152,643 Token 仍纳入结果，没有删除失败。

## 兼容性发现

零付费原生专项 **17/18 项符合预期**：原始会话完整保留；摘要不能清除待验证状态；当前源码修复与真实测试可完成；过期源码会被拦截；未变化工作区恢复时保留检查点。

未满足的一项：**受保护历史源码被摘要覆盖、此前又未被 ContextOS 替换为引用时，原内容仍在内部索引，可通过内部 recall 找回，但模型未获得 search_history 工具声明。** 当前检索入口主要依赖 ContextOS 自己选中/淘汰的引用，没有覆盖每一种摘要隐藏历史的情况。这是特定路径的入口缺口，不代表所有压缩都会丢失检索或普通修复都失败。

真实验收检查独立公开/隐藏代码行为、完整当前源码读取、最后修改后的真实正向验证、正常完成及修改范围；普通修复通过**不等于历史细节检索完整**。组合相对单独 ContextOS 的配对验收下降 0 个对照块。即使 Token 更低，也不能据此忽略入口问题。本轮未修改运行时、未开启默认自动压缩、未自动实施修复或下一优化。

## 条件与限制

short：空历史的小缓存键修复；protected：真实读取 README 构造受保护历史后的中型重试修复；evictable：真实文件枚举构造可回收历史后的大型 Unicode 修复。压力历史来自脚本执行真实工具，准备阶段不计费；不是模型自然产生的完整长会话。构造共同种子时关闭读取去重以形成刻意压力；真正运行阶段仍使用 v1 的正常读取去重，日常去重可能避免部分重复压力。三类自编缺陷与无关文件扩容不能证明生产项目泛化。

预检序列化请求：short 四组均 4,235 字节；protected 均 64,981；evictable 完整历史 68,497，ContextOS 18,154。字节不当作 Token。分别记录摘要尝试与有效检查点；四种顺序在重复间轮换。所有失败及负收益保留，不重试付费尝试；B1 的未知预留继续独立保留。

请求保护 80,000 字节，自动触发比例 0.8，近期保留 24,000 字节；ContextOS 软目标 32,000 字节、保留最近两轮工具。这是固定测试输入保护下的默认比例，不是全部开箱配置。任务输出 4096、原生摘要输出 1200，enabled/low 思考；24 次工具/轮、24 次供应商请求/运行（含摘要）、两次压缩尝试/轮，请求 180 秒/轮 300 秒。共同 USD 8 保护上限，单运行 USD 0.60。输入/缓存读取 0.80、输出 2.80 USD/百万，保守用量费用 USD 1.6702452，不是实际账单或供应商官方报价。所有缓存输入、思考输出及摘要调用均计入总 Token，不重复计数。

## 证据

已有确定性全套 268/268，无跳过。组合专项单列为 17/18，明确保留失败预期；已有 CI 通过不意味着该项被判为通过。首次检查器错误查找被转义的 JSON，而非原始检查点文本；付费前修正，零付费记录保留。
