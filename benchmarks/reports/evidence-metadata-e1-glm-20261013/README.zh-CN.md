## 限制

计划覆盖三种自编 JavaScript 缺陷在 12/120/1200 文件规模下重复，以及一个 30 轮检查后修复的流程；长会话没有实际启动。不是多个独立生产项目。bootstrap 只在同一任务的重复配对内重采样，区间用于探索，不能证明泛化。每个头部少 72 序列化字节是机制验证，不是实际 Token 数；真实模型操作路径也可能改变。比较器无法重置供应商缓存状态。所有普通、缓存读取、缓存写入输入和思考输出计入一次。

统一 GLM-5.3-flash enabled/low，输出/思考上限 4096/4095，ContextOS 32000 字节、v1 初始目录/读取去重、摘要关闭、能力反馈开启；24 工具/轮、100 请求/运行、160000 字节请求保护、请求 180 秒/轮 300 秒。没有新增路由或工具定义。
