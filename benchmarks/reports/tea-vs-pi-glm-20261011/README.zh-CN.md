## 一致性与验收

- GLM-5.3-flash；Anthropic Messages；enabled 思考预算 4,095；low 等级；输出上限 4,096。共同网关记录实际发送参数。
- 每组相同任务、固定 Git 提交和全仓库指纹；会话及 Pi 配置全新创建，交替运行顺序。工作区位于 TEA 仓库外，每次启动检查祖先指令，保留样本自己的指令。
- TEA 使用原生默认 `v1` 发现和完整历史；Pi 使用原生 read/edit/write/PowerShell，关闭扩展、技能、模板、自动重试、自动压缩和缓存预热。各自系统提示和工具不同，结论只针对该配置。
- 每任务每侧最多 24 个服务商请求，请求超时 90 秒、任务超时 300 秒。TEA 保留原生 24 次工具上限；通过的运行没有触发这些限制。
- 包含全部普通/缓存读/缓存写输入和输出；输出已含思考。有效实验中所有已提交请求的 usage 完整。缓存状态无法清空，未知用量不能按零计入。
- 两轮源码前后 SHA-256 相同：`fba9a98ced61424549dc4a0a5ed44eaad739fce6555c2007d3a67c444a0df9e6`，范围为 `src/*.mjs` 与 `scripts/*.mjs`。Pi CLI 哈希见英文报告与 JSON。
- 有效运行：`tea-pi-glm-isolated-20261011`（105 次请求）和 `tea-pi-glm-large-80k-20261011`（43 次）。公开 JSON 保留逐请求计数、哈希、共同参数与验收，不含密钥、私有路径或原始对话。

早期 `tea-pi-glm-live-20261011` 因 Pi 混入变化的祖先目录指令而整轮排除；随后 9 组全部重跑。该试跑的 111 次付费请求仍保留本地记录，并计入费用上限。

## 费用口径

全部测试上限 **$3**，含冒烟、排除试跑与两轮有效实验。保守计量分别为 $0.00018080、$0.27861760、$0.24810516、$0.16590600，合计 **$0.69280956**，不是服务商账单。

有效实验按 2026-10-11 [公开价格 API](https://www.packyapi.ai/api/pricing) 与 [NewAPI 公式](https://docs.newapi.pro/en/docs/guide/console/settings/rate-settings)，使用公开可用因子中较高的 0.9，输入/输出为每百万 $0.72/$2.52；缓存读按普通输入保守计费，缓存写按两倍输入预留。冒烟与排除试跑采用更保守的 $0.80/$2.80。不能据此宣称真实账单节省。

## 限制与后续改进点

每种配置每项任务仅一轮。只有缓存键、重试、Unicode 三类自编 JavaScript 问题；12/120/1,200 文件规模增加的是无关模块，目标错误复杂度不变。独立断言在 agent 工作区外执行，但没有 OS 隔离和保密留出集。不能代表多语言真实项目，也不是 TEA 与直接父版本的优化门禁。

大型重试补测的额外开销主要是更多请求累计重传的输入。后续应检查大仓库发现与额外工具循环，再用固定版本配对、重复试验和未见真实仓库验证；当前结果尚不能证明某个具体优化方法导致改善。
