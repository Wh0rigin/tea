## 如何理解结果

扩大摘要预算达到了直接目的：两次摘要实际超过旧版 1,200 Token 上限，全部完整采用，两次 Helm 均正常收尾，其中一次官方通过。新版并未实际写满 13,107 Token 上限。

但不能把总 Token 降幅全部归功于压缩：两次 Mnamer 候选都未触发摘要，它们的 Token 降幅主要体现运行路径波动；两次 Helm 累计 Token 反而增加。旧版提前失败会压低其总用量，因此多花 Token 完成后续开发未必是效率退步。应同时报告验收、完成状态和用量。

唯一两版均官方通过的配对是 Mnamer r2，但候选没有摘要，且基线本地容量停止、由独立验收判通过；这不能识别摘要本身的节省效果。若要求两版都正常完成且官方通过，没有可用配对。
