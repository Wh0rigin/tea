# 新版 TEA 与历史 Pi / Claude Code 对比

[English](README.md)

![三 Agent 对齐场景对比](three-agents.png)

## 数据来源

新版 TEA 为公平检索修复 **d76f45f**，Pi **0.87.1** 和 Claude Code **2.1.281** 使用历史 fresh-v5 实验数据。本次**零新增 API 调用**，不是三方同轮重测；不修改历史 Token 或判分。

只对齐新版 TEA 已测的 6 个小型/大型场景，各重复 3 次，**每个 Agent 18 次，共 54 次、302 笔用量完整的请求**。已核对任务提示哈希、初始源码哈希、文件数；实际模型控制相同：**GLM-5.3-flash、enabled/low、4096 输出上限、4095 思考预算**。端点哈希、请求字节保护和每例请求/时间上限一致。各自原生提示、工具和记忆策略保留；Claude Code 使用的是 GLM，不是 Claude 模型。

## Token 结果

- 小型：TEA **76,095**，Pi **106,969**，Claude **263,065**；TEA 分别减少 **28.86% / 71.07%**。
- 大型：TEA **75,583**，Pi **564,425**，Claude **373,057**；TEA 分别减少 **86.61% / 79.74%**。
- 合计：TEA **151,678**，Pi **671,394**，Claude **636,122**；TEA 分别减少 **77.41% / 76.16%**。

均包含缓存输入、思考输出和所选场景的全部尝试。

## 正确率与图形

完整验收 **TEA 18/18、Pi 18/18、Claude 12/18**；三方代码行为、最终文件范围、声明读取要求和流程完成均为 **18/18**。Claude 另 6 次仅最终验证未确认，保留三角形，不改成通过或代码失败。双方完整通过的 TEA/Claude 12 对诊断子集减少 **78.99%**，不能替代 18 次完整数据的结果。

圆点为完整通过；三角形为最终验证未确认；失败叉号会保留散点但排除出柱形，未知用量不填零。本次所选场景没有其他失败或未知用量，所以每根柱子均包含 9 次已测尝试，柱形和标注百分比口径一致。

新版没有中型及长会话测量，未用旧 TEA 版本填补这些位置；此前图表保留为历史证据。修复版的小型 Unicode 对父版本回退也仍保留。
